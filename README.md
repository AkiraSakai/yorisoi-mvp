# ヨリソイ — ナラティブGPS

親子の「断絶」を、どちらも責めずにナビゲートするメンタル総合サービスの MVP プロトタイプ。

> 👵 親「自分が正しい」と信じている → 🧑 子 それを苦痛に感じる → ↔️ 互いに距離を取り、断絶へ

**ナラティブGPS** は、どちらかを「直す」のではなく、2人の物語（価値観の地図）の現在地を映し、断絶しない迂回ルートを案内します。

## 機能

| タブ | 内容 |
|---|---|
| 🧭 GPSルート案内 | 言われた一言から、相手の真意・断絶リスク・角が立たない返信案を案内 |
| 🌿 オアシス発見 | 親の年代と「好き」から、寄り添える話題・一緒にできること・贈り物ヒントを提案 |
| 💣 断絶ポイント地図 | 衝突しやすい話題と迂回の歩き方 |
| 🔄 セルフアップデート | 「知らなかっただけ」を責めない今どき常識カード |
| 💗 メンタルチェック | 親子関係のしんどさを5問でセルフチェック |

自己完結の単一 HTML（外部依存なし）。
